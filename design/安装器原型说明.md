# CodeWF 安装器交互提案

直接打开 [CodeWF.安装器原型.html](CodeWF.安装器原型.html)。文件内嵌全部样式、脚本与矢量图形，可独立复制、离线打开。

**当前交付是待验收设计。没有修改任何仓库的安装脚本、安装器、发布工作流或系统设置。验收后再决定实施范围。**

## 设计范围

统一使用 .NET 品牌紫 `#512BD4`，保留清楚的标题、步骤、安装目标与主操作。浅色、深色、跟随系统和简体中文、英文独立切换。动效用于页面进入、按钮状态与进度反馈；遵循系统“减少动态效果”，也提供手动开关。

- Windows：欢迎、MIT 许可阅读、目录与安装范围、快捷方式、确认、进度、完成，以及已有安装的修复、卸载、文件占用错误、重试和取消确认。路径需要绝对路径，系统目录不能作为安装目标。所有用户安装另行展示系统授权，示例没有声称安装包已获得可信签名。
- macOS DMG：Finder 窗口、`.app` 与 Applications 文件夹、拖入复制、已有应用替换提示、复制进度、完成与推出。支持拖放，也可聚焦应用图标按 Enter 演示复制。
- macOS Installer：作为**可选 PKG 提案**单独预览标准向导。目标磁盘与 `/Applications` 由平台模型表达，不提供 Windows 路径或桌面快捷方式选项。
- Linux DEB：系统软件安装器的包详情、架构、依赖、授权、安装与移除。没有自行选择安装目录、安装范围或快捷方式的虚构功能。

原型工具栏与窗口外的步骤预览用于评审。进度、空间、版本 `1.0.0`、账户与目录均为演示数据。密码栏只读且使用固定示例值，不收集密码。整个文件不调用系统接口，不发送网络请求，不写本地存储。

## 已核实的现有事实

来源是两个库和各应用仓库当前的 `.iss`、Linux 打包脚本、macOS 打包脚本、根目录 `LICENSE` 与 README。核实日期：2026-10-16。

| 项目 | Windows 当前安装权限 | 当前桌面快捷方式 |
| --- | --- | --- |
| CodeWF.Avalonia Demo | 当前用户 | 可选，默认关闭 |
| CodeWF.Toolkit Demo | 当前用户 | 可选，默认关闭 |
| Vex | 当前用户 | 可选，默认关闭 |
| CodeWF.Toolbox | 当前用户，可选择提升权限 | 默认开启 |
| IEditor | 当前用户，可选择提升权限 | 默认开启 |
| NexusDash | 当前用户，可选择提升权限 | 默认开启 |
| AvaGithubDesktop | 当前用户，可选择提升权限 | 默认开启 |
| ClearC、HomeLedger、KidWall、QuickApp、Zhijian、Zitie | 管理员 | 可选，默认关闭 |

原型的产品切换遵循上述范围，禁用当前安装脚本不支持的范围选项。这里描述的是安装脚本的现状，不判断各应用是否有必要要求管理员权限。

当前 Windows 安装器由 Inno Setup 构建，架构为 x64；Linux 包为 x64 / arm64 DEB；macOS 为 x64 / arm64 `.app` 与 DMG。DMG 中已有 Applications 软链接。DEB 已包含系统启动入口、图标及原生系统库依赖。

Vex 已注册 `.md`、`.markdown`、`.mdown` 的图标、打开方式候选与右键入口，不强行更改系统默认应用。原型把这项能力显示为可选项；当前 `.iss` 的注册本身并不是由该选项控制。

这些仓库均使用 MIT 许可证。原型许可页保留原始英文条款与各仓库的版权署名，界面文案可以切换语言。

## 需要验收的新增设计

自定义步骤栏、完整深浅外观、品牌图形、动画、统一许可阅读页、维护入口、修复流程、明确的数据保留选择、Vex 关联选项和 PKG 都是设计提案，不能视为当前安装器已经支持。

Windows 首选继续复用现有 Inno Setup 的安装、卸载与提权能力。具体版本可实现的深色控件、步骤栏、自绘图形与动效，需要在实施时验证，不能以浏览器原型证明原生安装器能够逐像素还原。UAC 应继续交给 Windows，不能用应用自制窗口代替。

DEB 的安装界面由发行版的软件管理器提供，颜色与细节受桌面环境影响；不能通过修改包元数据让所有 Linux 软件管理器统一成这份外观。应统一应用图标、名称和元数据，并保持系统授权流程。

DMG 中可设计背景与图标布局，Finder 窗框和系统复制对话框仍由 macOS 管理。原型为了展示复制、授权与错误流程而模拟这些系统界面，不代表应用将接管系统窗口。PKG 是独立交付方式，默认仍推荐现有 DMG。

个人数据默认保留是本次提出的交互方向。实施前须逐应用确认设置、文档与缓存路径，尤其不能把应用安装目录一并清理等同于安全地保留个人数据。当前部分脚本清理 `{app}` 的行为仍需结合真实路径审查。

## 交互验收

先体验 Windows 完整流程，再选择 CodeWF.Toolbox 检查“所有用户”与授权；选择 Vex 检查 Markdown 打开方式。使用右下角情景切换检查修复、卸载和错误恢复。

平台切换后分别体验 DEB 安装、DMG 拖放、已有应用替换，以及可选 PKG。确认主操作明确、中文与英文没有裁切、深浅模式层次清楚。Tab、Shift+Tab、Enter、Escape 和 Alt+左方向键可用于相应导航；对话框约束焦点范围。

自动检查使用既有 Playwright 依赖：

```powershell
node E:\github\Libs\CodeWF.Avalonia\design\tests\audit-installer.cjs
```

脚本把单个 HTML 复制到空目录，阻止外部文件与网络请求，检查两种宽度（1440、1120）、中英文、浅深色和平台页面的横向裁切，并实际操作许可门禁、路径校验、目录选择、安装选项、提权确认、完成、修复、卸载、重试、取消、拖放与系统主题。默认输出在 `E:\github\temp\installer-prototype-audit`，可通过 `CODEWF_INSTALLER_AUDIT_OUTPUT` 调整。

这些是浏览器交互和布局检查，不能替代 Windows、macOS、Linux 的真实安装、权限、签名、公证和卸载验收。
