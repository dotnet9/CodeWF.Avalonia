# 配色与排版令牌规则

> **状态**：草案 v1（`ruleVersion: 1`）
> **地位**：本文件（含附录 A 的机器可读数据块）是控件层配色、Markdown 层主题、密度与尺寸档的**唯一事实源**。
> C# 派生引擎、三个 HTML 原型的生成器、Demo 与应用的一切令牌常数必须源自本文，**禁止在代码内另行抄写常数**。
> 常数标定阶段允许调整附录 A 的取值，调整后必须同步修改本文并递增 `ruleVersion`。

---

## §0 范围与分层

```
┌─ 控件层（不含 Markdown 渲染内容） ────────────────────────────┐
│ 8 色编写层 → 派生引擎 → 语义键(~30) → Semi/Ursa 覆写 → 控件    │
│ 密度三档（紧凑/正常/宽松）：字号/控件高/间距/圆角               │
└──────────────────────────────────────────────────────────────┘
┌─ Markdown 层（渲染出的文档内容） ─────────────────────────────┐
│ 主题自成体系：accent/decoration × 双明暗 + 内置中性阶梯         │
│             + 排版相对量 + 纸面块（backdrop / contentSurface）  │
│ 尺寸档（紧凑/正常/宽松）：基准 BodySize，与控件层密度独立       │
└──────────────────────────────────────────────────────────────┘
```

**两层之间的四个接缝（全部边界，别在别处耦合）：**

1. **明暗联动**：切明暗时 Markdown 主题切到自己的 Dark 侧，但不随界面配色变；
2. **纸面归属**：无缝型主题渲染在控件层 `Paper` 上；成品型主题自带纸面（见 §8）；
3. **Mermaid / 图表**：图表需要多色，从控件层 accent 派生（维持现状映射，写在 §4）；
4. **编辑器源码区**：chrome（背景/当前行/行号/选区）归控件层；**字号归 Markdown 尺寸档**——源码与预览都是"读文档"，同档。

**术语表**

| 术语 | 含义 |
|---|---|
| 编写层 | 用户/设计者需要手写的最小输入（控件层 8 色、Markdown 主题参数） |
| 消费层 | 控件与样式实际引用的稳定键（语义键、`CodeWFMarkdown*`），全部由派生引擎生成 |
| 派生 | 由基础色按固定公式（透明度叠加/混合）计算消费层取值 |
| 烘焙 | 派生时把透明度合成到已知底色上，输出**不透明**色；控件永远消费确定色 |
| 快照 | 从本规则生成、供各 HTML 原型使用的 CSS 令牌文件，带版本戳，禁止手写 |

# 第一部分 · 控件层

## §1 基础色 8 键

每个键必须提供浅色、深色两态取值。**最小编写量是 4 键**（paper/surface/ink/accent）：状态四键有全局默认值（附录 A `statusDefaults`），仅当与 accent 色相冲突时覆盖（如 Crimson 的 danger、Amber 的 warning）。

| 键 | 语义 | 浅色态取值原则 | 深色态取值原则 |
|---|---|---|---|
| `paper` | 纸面：编辑器、文档预览、阅读面的底 | 近白，可带轻微色温（明度约束见 §5） | 近黑，可带轻微色温 |
| `surface` | 面板、侧栏、状态栏、卡片 | 比 paper 深一档（海拔 -1） | 比 paper 亮一档（海拔 +1） |
| `ink` | 主文字，也是一切中性派生的"墨" | 深色（近黑带主题色温） | 浅色（近白带主题色温） |
| `accent` | 强调：链接、选中、焦点、品牌位 | 深而饱满（白字可读） | 亮而饱满（墨字可读） |
| `danger` | 错误状态 | 全局默认，冲突时覆盖 | 同左 |
| `success` | 成功状态 | 同上 | 同上 |
| `warning` | 警告状态 | 同上 | 同上 |
| `info` | 信息状态（缺省可复用 accent） | 同上 | 同上 |

## §2 九套高对比配色

**高对比 ≠ 高饱和。**本套配色的量化标准（生成器必须校验，见 §5）：

- 正文 ink↔paper ≥ **10:1**（AAA 级）；
- 次要文字 muted ≥ 4.5:1；accent 作为文字（链接）在 paper 上 ≥ 4.5:1；
- 深色态表面至少有 2 级可感知海拔差；
- 表面保持近中性（色温偏染 ≤ 5%），对比来自墨深 + accent 色度，**不允许**靠深艳纸面做对比。

九套名单（3×3 九宫格目录，数据见附录 A `palettes`）：

| Key | 名称 | 定位 |
|---|---|---|
| `graphite` | 石墨 | 无彩色，纯明度对比的基准套 |
| `indigo` | 靛蓝 | 经典蓝，替代旧默认蓝的现代取值 |
| `teal` | 青碧 | 冷青 |
| `pine` | 松绿 | 沉稳绿 |
| `sky` | 天青 | 清朗蓝青，介于靛蓝与青碧之间 |
| `amber` | 琥珀 | 暖金 |
| `crimson` | 绯红 | 冷艳红 |
| `violet` | 紫晶 | 紫 |
| `terracotta` | 陶土 | 暖陶 |

**替换声明**：本 9 套直接替换库内现有 16 套内置配色，不做旧 key 兼容（自用为主）。原 16 套 axaml 在迁移时删除，`StudioPalette` 枚举改为字符串 Key 注册表（§13）。

## §3 派生规则表

固定公式，不随配色变；`@` 表示透明度叠加后**烘焙**到指定底色；`mix(A→B, n%)` 表示 A 向 B 混合 n%。

| 派生键 | 浅色态 | 深色态 | 说明 |
|---|---|---|---|
| `muted` | ink@64% → paper | 同左 | 次要文字 |
| `disabled`(文字) | ink@40% → paper | 同左 | |
| `disabled`(底) | ink@6% → paper | 同左 | |
| `border` | ink@12% → paper | ink@16% → paper | 弱分隔线 |
| `controlBorder` | ink@20% → paper | ink@26% → paper | 输入控件描边 |
| `hover` | ink@5% → surface | ink@7% → surface | 悬浮 |
| `raised` | ink@4% → paper | ink@6% → paper | 当前行、浅浮层底 |
| `selected` | accent@12% → paper | accent@18% → paper | 选中项背景 |
| `accentSoft` | accent@10% → paper | accent@16% → paper | 软强调背景 |
| `selection` | accent@24% → paper | accent@30% → paper | 文本选区 |
| `statusSoft` | status@12% → paper | status@18% → paper | danger/success/warning/info 各一份 |
| `scrim` | 黑@40% | 黑@60% | 模态遮罩，用纯黑不用 ink |
| `primaryHover` | mix(accent→paper, 8%) | mix(accent→白, 8%) | 主按钮悬浮 |
| `primaryPressed` | mix(accent→ink, 10%) | mix(accent→黑, 12%) | 主按钮按压 |
| `primaryDisabled` | ink@12% → paper（底）/ ink@40%（字） | 同左 | |
| `gradientStart` | = accent | = accent | 标题渐变起点 |
| `gradientEnd` | mix(accent→白, 25%) | mix(accent→paper, 20%) | 渐变终点（全界面唯一渐变） |
| `overlay` | = surface | = surface | 弹窗、菜单浮层底，靠阴影分层 |
| `onAccent` | 自动判定（见下） | 同左 | accent 上的文字 |

**onAccent 自动判定**：分别计算白字与黑字在 accent 上的对比度，**取更高者**（浅色态 ink 近黑、等价于黑字；深色态 ink 为亮色不可作 accent 上文字，故候选固定为黑）。

**烘焙原则**：派生引擎输出的全部是不透明色。控件、导出、对比度校验永远面对确定色值；透明度只是规则的思维语言，不进入消费层。

## §4 语义键全集（消费契约）

每个 `StudioXxxColor` 键都有成对的 `StudioXxx` Brush（现有惯例，保持）。

**表面**：`StudioBackgroundColor`（窗口舞台）、`StudioSurfaceColor`、`StudioPaperColor`、`StudioRaisedColor`、`StudioOverlayColor`
**文字**：`StudioTextColor`、`StudioMutedColor`、`StudioDisabledColor`、`StudioOnPrimaryColor`
**品牌交互**：`StudioPrimaryColor`、`StudioPrimaryHoverColor`、`StudioPrimaryPressedColor`、`StudioPrimaryDisabledColor`、`StudioAccentColor`、`StudioAccentSoftColor`、`StudioSelectedColor`、`StudioFocusRingColor`（= accent）、`StudioGradientStartColor`、`StudioTextGradientEndColor`
**状态**：`StudioDangerColor`、`StudioDangerSoftColor`、`StudioSuccessColor`、`StudioSuccessSoftColor`、`StudioWarningColor`、`StudioWarningSoftColor`、`StudioInfoColor`、`StudioInfoSoftColor`
**结构线**：`StudioBorderColor`、`StudioControlBorderColor`
**遮罩/选区**：`StudioScrimColor`、`StudioSelectionColor`

**Studio → Semi 覆写映射**（Ursa.Themes.Semi 消费 SemiColor*，自动跟随）：

| Studio 语义 | Semi 键 |
|---|---|
| Primary | `SemiColorPrimary` |
| AccentSoft | `SemiColorPrimaryLight`，其 Pointerover/Active = accent@14% / accent@18% |
| Paper | `SemiColorBg` |
| Hover | `SemiColorFill` |
| Border | `SemiColorBorder` |
| Text | `SemiColorText` |
| Danger / Success / Warning / Info | `SemiColorDanger` 等，Soft → `*Light`，按压态 → `*Active`（= status@18%） |

Semi 的 `Background0..4`、`Fill0..2` 细分键按需在此表补映射；原则不变：**语义键是唯一入口，映射表是唯一桥接处**。

## §5 Paper 约束与对比度校验

**Paper 明度区间**（无缝型 Markdown 主题解耦的前提，见 §8）：浅色态相对亮度 ≥ 0.90，深色态 ≤ 0.12，且低饱和（色温偏染 ≤ 5%）。

**校验清单**（配色生成/导入时执行，全部给出具体数字报告）：

1. ink↔paper ≥ 10:1；muted↔paper ≥ 4.5:1；
2. accent 作为文字在 paper / surface 上 ≥ 4.5:1；onAccent↔accent ≥ 4.5:1；
3. 状态色四键同上；
4. Paper 落在明度区间内。

**失败策略**：不阻断保存，但在配色编辑器逐条提示，并给出"最近的可达标取值"建议（如 accent 加深/提亮一档）。

## §6 密度三档

**显式值表，不用统一乘数**（乘数会把图标压糊、让圆角失控，显式表可以单独钉住例外）。三档全部度量键：

| 键 | 紧凑 | 正常 | 宽松 |
|---|---|---|---|
| FontSizeCaption / Body / Subtitle / Title / Display | 11/12/14/17/22 | 12/14/16/20/26 | 12/15/17/21/28 |
| ControlHeightSm / Md / Lg | 24/28/34 | 28/32/38 | 32/36/44 |
| PaddingSm / Md / Lg | 4/8/12 | 6/10/14 | 8/12/18 |
| GapSm / Md / Lg | 4/8/12 | 6/10/16 | 8/12/20 |
| CornerRadiusSm / Md / Lg | 4/6/8 | 6/8/10 | 8/10/12 |
| ListRowHeight | 26 | 30 | 36 |
| IconSize | 14 | 16 | 18 |

- **切换机制**：Avalonia 侧三份显式 ResourceDictionary 整树换入换出；原型侧 `:root[data-density=…]`。
- **边界**：编辑器源码区**字号不归此层**（归 §11 尺寸档）；源码区 chrome（行号、当前行、选区高亮）归此层。圆角跟密度走是刻意的——紧凑时内容受挤压，大圆角会切字。

## §7 用户配色 JSON Schema

```json
{
  "ruleVersion": 2,
  "key": "user:night-ink",              // 用户配色必须以 user: 前缀
  "name": "夜墨",
  "light": { "paper": "#FDFCF8", "surface": "#F2F1EA", "ink": "#1C1B16", "accent": "#3E5C46" },
  "dark":  { "paper": "#121410", "surface": "#1A1D18", "ink": "#E8EAE2", "accent": "#9DC7A8" },
  "overrides": {                        // 可选逃生门，覆盖任意派生键
    "light": { "border": "#D8D6CC" },
    "dark": {}
  }
}
```

- 状态四键缺省取全局默认；可写在 `light/dark` 里覆盖；
- `overrides` 默认为空，规则覆盖 95% 场景，剩余场景（品牌双色等）不破坏模型；
- 生成器加载后即跑 §5 校验。

# 第二部分 · Markdown 层

## §8 主题模型

**编写层组成**：`accent`（强调色）+ `decoration`（装饰色：标题线、引用条、tint）各浅/深两态 + 排版相对量（§10）+ 装饰偏好（标题装饰形式、引用样式、字体族）+ **纸面块（可选）**。

**两个主题原型：**

| 原型 | 纸面 | 中性阶梯 | 适用 |
|---|---|---|---|
| 无缝型 | 不声明，渲染在控件层 `Paper` 上，跟随界面配色与明暗 | 内置默认阶梯（按近白/近黑纸调校） | Basic、Simple、InkBlack |
| 成品型 | 自带 `backdrop`（背景幕：纯色纸/渐变/纹理/彩底）+ `contentSurface`（文字真正落在的一面），各声明浅/深两态 | 携带为自己纸面调校的阶梯 | GeekBlack、公众号风格 |

**规则**：

1. 文字对比度永远对 **contentSurface** 校验（不是 backdrop）；
2. 预览视口的滚动条/选区/焦点环归控件层 chrome；
3. **导出默认剥离 backdrop**（公众号不支持全页背景，导出样式以 contentSurface 为准）；主题可显式声明 `keepBackdropOnExport`（导出独立 HTML 场景）。

**内置中性阶梯默认值**（无缝型用；成品型可携带覆盖）：

| 键 | 浅色态 | 深色态 |
|---|---|---|
| 正文 | `#30343B` | `#E4E5E7` |
| 次要文字 | `#606770` | `#AFB4BB` |
| 边线 | `#DDE1E5` | `#484C53` |
| 代码底 | `#F6F7F8` | `#292B2F` |
| tint 混色基纸 | `#FFFFFF` | `#202124` |

**保留套的逐套改造清单**（每套必做三件事）：

1. **对比度校验**：accent/decoration 对各自 contentSurface 过 §5 同款阈值；
2. **暗色侧检查**：LightText/DarkText、纸面双态齐全且对比达标；
3. **相对量化改造**：绝对字号改为 §10 比例；成品型补纸面块声明。

## §10 排版相对量规范

主题**只定义比例**，基准由尺寸档（§11）注入；基准一变全页等比缩放。默认比例（主题可覆盖）：

| 元素 | 比例（× 基准 BodySize） |
|---|---|
| H1 / H2 / H3 / H4 / H5 / H6 字号 | 1.90 / 1.55 / 1.30 / 1.15 / 1.05 / 1.00 |
| 标题上边距 / 下边距 | 1.40 / 0.45 |
| 段落下边距 | 0.85 |
| 列表项间距 / 嵌套缩进 | 0.30 / 1.50 |
| 引用 padding（纵/横）/ 圆角 | 0.60 / 1.00 / 0.40 |
| 代码块字号 / padding（纵/横） | 0.92 / 0.90 / 1.00 |
| 表格单元格 padding（纵/横） | 0.45 / 0.75 |
| 分隔线上下边距 | 1.20 |

行高由主题声明（`leading`，推荐区间 1.5–1.9；标题行高固定 1.3）。字体族三选一：`sans / serif / mono`（解析沿用 `ArticleTypography.ResolveFont`）。

## §11 尺寸档

| 档 | 基准 BodySize |
|---|---|
| 紧凑 | 13 |
| 正常 | 15 |
| 宽松 | 17 |

- **与控件层密度独立，不联动，无"跟随"开关**——UI 密度是省空间，阅读字号是阅读偏好，动机会互相干扰；
- 命名与控件层三档一致（紧凑/正常/宽松），存储与切换各自独立；
- **预览与源码编辑区同档**；
- 档位只提供基准，段距/标题/引用等全部经 §10 比例自动等比，无额外间距键。

## §12 导出约定

- 导出 CSS（`ExportCss` / `CompactExportCss`）由主题参数生成，**独立于运行时一切设置**（UI 密度、尺寸档、明暗）；
- 导出基准字号固定 15（主题可用 `exportBase` 覆盖）；
- backdrop 默认剥离；主题声明 `keepBackdropOnExport` 时保留。

# 第三部分 · 共享

## §13 用户自定义机制

**注册表模式**（照 `MarkdownTypographyThemeRegistry` 先例）：配色与主题都是字符串 Key 注册表，运行时可注册。

**增删改规则**：内置只读；可"复制为我的配色/主题"（`basedOn` 或全量导出后编辑）；用户项可增删改；删除即物理删除（自用为主，无 hidden 兼容负担）。

**Markdown 主题 JSON Schema**（示例）：

```json
{
  "ruleVersion": 2,
  "key": "user:misty-jade",
  "name": "雾玉",
  "basedOn": "LanQing",
  "accent":     { "light": "#2C7A7B", "dark": "#7FD1CC" },
  "decoration": { "light": "#B7791F", "dark": "#F6C667" },
  "paper": {
    "light": { "backdrop": "#F4F7F5", "contentSurface": "#FFFFFF" },
    "dark":  { "backdrop": "#14171A", "contentSurface": "#1B1F23" }
  },
  "typography": { "leading": 1.75, "font": "serif", "headings": { "h2Decor": "leftBar" } },
  "keepBackdropOnExport": false
}
```

不声明 `paper` 即无缝型。加载数据后反序列化为 `ArticleTypography` 同构 record，`CreateResources()` 注册，导出 CSS（含紧凑版）由模型生成。

## §14 快照与版本化

- `palette-tokens.css`（两个库原型）与 Vex 的 `palettes.css` 均由生成器从附录 A 产出，**带版本戳 = 包版本**（如 `12.1.4.x`），文件头注明上游版本；
- **禁止手写快照**（Toolkit 原型的快照已发生过漂移，此规则即为止血）；
- 各仓快照独立携带、构建时不跨仓读取；上游升版后重新生成并提交。

## §15 装饰语言基线

组件样式改造时的对照原则（只定原则，不逐控件展开）：

1. **海拔分层，边框退位**：层级用表面色阶差 + 极淡阴影表达；1px 边框只留给输入控件与分隔线；
2. **圆角体系**：6 / 8 / 12（小控件 / 卡片 / 浮层），随密度档缩放（§6）；
3. **字重**：400 / 550 / 650 三档，标题靠字号与行高立层级，不用 700 加粗；
